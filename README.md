# NDINA Gallery — Shopify theme

Dawn-based Shopify theme restyled for NDINA Gallery (shop.ndina.gallery).

- Typeface: Jost (Shopify font library) — headings 500, body 400
- Palette: terracotta `#B84A30`, cream `#FBF8F3`, ink `#1A1A1A`
- Product page: "One of a kind · original work" label when tracked stock = 1; sold items show "Sold" (locale edit)
- Brand layer lives in `assets/ndina.css`

Connect in Shopify admin: Online Store → Themes → Add theme → Connect from GitHub → this repo, `main`.
Upload the NDINA logo in Customize → Header (logo image).
